# The English course: content and how to grow it

The course lives in plain JSON files in `backend/src/main/resources/curriculum/` and is loaded and validated at start-up
(`Curriculum.java`). Nothing is generated by a model and nothing is claimed that is not in the files.

## What is in the course today (counted from the files)

| Part | Count | What each item has |
|---|---|---|
| Grammar | **67 lessons** in 5 levels (14, 12, 13, 13, 15) | definition, explanation, structures, examples, common mistakes, exercises with an explanation for every answer, a short test. Includes Determiners, Interjections, Noun clauses, Causatives, Advanced prepositions and Formal and informal English |
| Vocabulary | **1,929 words** (levels 1 to 5: 274, 328, 536, 605, 186) | meaning, Kannada, part of speech, example, common usage (collocation), synonyms, theme, pronunciation button (the device's own voice, not scored), a practice question |
| Phrasal verbs | **299 verbs with 320 meanings** (levels 1 to 3: 95, 95, 109) | meaning, Kannada, separable or inseparable, common usage, theme, register, examples, other meanings, a common mistake where there is one, practice questions |

**Targets not reached.** The goal was 2,000 vocabulary words and 2,000 phrasal verb entries. The course has **1,929 words** (71 short) and **299 phrasal verbs
(320 meanings)**, far from 2,000. Real phrasal verbs are limited in number: counting each meaning as an entry, a verified 2,000 would need
many more carefully written lines. Level 5 vocabulary is the thinnest (186). The structure, the generator and the checks are in place, so the rest can be
added in batches (below) and the counts here are re-read from the files every time.

**Kannada has not been reviewed by a native speaker or teacher.** It is shown only when the learner has chosen Kannada as the explanation language.
Pronunciation help is the device's text-to-speech voice (a "Hear it" button); it is not scored and is not a phonetic transcription.

## The daily plan

`LearnService` chooses one plan per day from a fixed sequence (not random): grammar lesson, vocabulary theme, phrasal verbs, a quiz, a speaking
exercise and, when words are due, revision. A plan not finished carries over to the next day. "Learn more" is limited to 3 per day. Spaced repetition
uses 5 boxes (intervals 0, 1, 3, 7, 14, 30 days); a word counts as learned from box 3. All of this is stored per learner in the database; no figure
on screen is made up.

## Exercise types

Multiple choice, fill in the blank, correct the sentence, identify the mistake, make a sentence, choose the phrasal verb, match (`left=>right||left=>right`),
rearrange the words, and the daily and revision tests. `Curriculum.java` checks that every question can be answered, that a "correct the sentence"
question really has a faulty sentence, and that a "rearrange" question is not already in order.

## Adding content

Add lines to the compact source files and run the generator:

```
tools/curriculum/words/more-N.txt      word|part of speech|meaning|Kannada|example (must contain the word exactly)|common usage|synonyms|theme|note
tools/curriculum/phrasal/more-N.txt    verb|meaning|Kannada|SEPARABLE, INSEPARABLE or NONE|usage|theme|register|example 1|example 2|example 3|other meanings|wrong>>right>>why
python tools/curriculum/check_batch.py tools/curriculum/words/more-4.txt     # lists every problem in a batch at once
PYTHONIOENCODING=utf-8 python tools/curriculum/build_curriculum.py            # merges and prints the true totals
```

The generator never changes or duplicates an existing item (a word or verb already present is skipped, so the printed "+N new" is the real number added),
numbers them, builds the practice questions, and stops with a message for a malformed line, an example without the word, an unknown theme or part of
speech (nouns, verbs, adjectives, adverbs and prepositions are supported), a word that is also a phrasal verb, or a "mistake" equal to its correction.

The backend checks everything again when it starts and in `CurriculumTest`: ids and levels, every required part, no duplicate word or phrasal verb
anywhere in the course, no word that is also a phrasal verb, blanks that do not give the answer away, and that every question can be answered.

## Quality

The entries were written by hand for this project and checked by the tests above for structure. **They have not been reviewed by a language
teacher.** Before the course is published, a teacher should read the meanings, the separability notes, the "common mistakes" and all Kannada.
