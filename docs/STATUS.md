## Known limits

- Voice transcription / spoken-English analysis is **not implemented**. The coach reviews text the learner types; it never hears calls.
- Single global matching queue; the signalling socket registry is per process (scale-out needs sticky sessions or Redis pub/sub).
- No automatic suspension thresholds (moderators decide); reports are reviewed in the web admin only, with no email alert.
- Android app: no push notifications (reminders are email), arm64 only by default, admin console is web-only, no iOS build.
